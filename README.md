# Rock Paper Scissors

A real-time computer vision project that captures hand gestures using a webcam to play Rock-Paper-Scissors.

## Tech Stack
* **Python**
* **OpenCV** (Computer Vision & Video Feed)
* **MediaPipe** (Real-time Hand Tracking)

## Features
* Detects hand gestures via live webcam input.
* Leverages MediaPipe Hands for landmark identification and gesture recognition.
* Processes real-time video frames efficiently using OpenCV.

## How to Run

1. Clone this repository:
```bash
git clone https://github.com/Yashfeen123/rock-paper-scissors.git
```
2. Install the required dependencies:
```bash
pip install opencv-python mediapipe
```
3. Run the webcam script:
```bash
python data_webcam.py
```
